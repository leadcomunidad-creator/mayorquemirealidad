# Inicio de continuidad — MRV WEB

Este directorio es el **Paquete Vivo de Continuidad**. Su propósito es que un chat nuevo pueda retomar el proyecto en el mismo punto, sin usar memoria de conversaciones anteriores ni buscar copias alternativas.

## Instrucción para un chat nuevo

> Lee íntegramente `README.md`, `AGENTS.md` y todos los documentos de `CONTROL_MRV/` en el orden del README. Luego ejecuta `git status --short --branch` y `git ls-remote origin refs/heads/main`. Resume: raíz canónica, commit remoto, estado local, entrega más reciente, recursos pendientes y siguiente acción segura. No edites ni publiques todavía.
